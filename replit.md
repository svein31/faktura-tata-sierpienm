# Fakturo

## Project overview

Fakturo is a Polish VAT invoicing SaaS built with Next.js App Router,
Prisma, and SQLite. The project includes authentication, invoice management,
notifications, and demo-mode KSeF/GUS integrations.

The existing project structure is intentional and should be preserved.
Cyber_Folks deployment helpers live in both `deploy/cyberfolks/` (full
documentation) and `cyberfolks/` (copyable deployment helpers).

## User preferences

- Preserve all existing files and the current folder structure.
- Keep the Cyber_Folks deployment compatible with a subdomain without
  hardcoding a specific domain.
