# Export schema fixtures

`pain.001.001.09.xsd` is the ISO 20022 customer credit transfer schema, generated 2019-02-22. Retrieved from https://github.com/fortesp/xsd2xml/blob/master/tests/resources/pain.001.001.09.xsd for independent XML validation. Passing XSD validation does not certify bank-specific import requirements.

Bank profiles checked against mBank documentation: https://www.mbank.pl/pdf/msp-korporacje/bankowosc-elektroniczna/mbank_pain00100109_pl.pdf and https://www.mbank.pl/indywidualny/konta/pytania-i-odpowiedzi/platnosci-elixir/ . Generic CSV requires field mapping in the destination bank.
