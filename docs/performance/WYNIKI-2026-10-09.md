## Obciążenie — 1000 kont w bazie, maksymalnie 20 wykonawców

Przygotowano **1000 syntetycznych kont i 30000 początkowych faktur**, po 30 dokumentów na konto. To liczność fixture, nie 1000 równoczesnych użytkowników. Każdy etap ma 6 s zadań plus czas dokończenia trwających żądań. Model jest zamknięty: wykonawca wysyła następne żądanie po odpowiedzi, bez czasu namysłu i bez pomiaru oczekiwania przed wysłaniem następnego żądania. Odrębna liczba aktywnych tenantów w rampie nie jest zapisywana. PDF wszystkich fixture rozgrzano pojedynczymi sekwencyjnymi odczytami przed rampą.

Mieszanka: bootstrap, lista, wyszukiwanie, szczegóły, utworzenie dokumentu i rozgrzany PDF. Baza i aplikacja działają na tej samej maszynie; parametry hosta, cgroup i profile są w JSON. Próba nie odtwarza Netlify/Atlas, cold-start, internetowego RTT, dostawców ani ruchu o stałej częstotliwości napływu.

## Zmierzony efekt wyłączenia niepotrzebnego prefetch

Osobny identyczny fixture zimnego prywatnego dashboardu przed i po poprawce, w Chromium/WebKit/Firefox, wykazał w każdym silniku: niezamierzone początkowe pobrania tras **13→0**, skrypty **26→22**, szacowany gzip **348 893→322 964 B** (**−25 929 B /−7,43%**). Ten prywatny pomiar używa standardowego gzip Node, publiczny web-lab poziomu 9; nie mieszamy ich sum ani nie przypisujemy temu izolowanego zysku LCP w ms.

W aktualnym buildzie 33 rzeczywiste scenariusze intent/network potwierdziły prawdziwe 200 dla formularza po pointer/focus oraz pominięcie warmupu dla SaveData/2G/slow-2G; wskazówki połączenia były kontrolowanymi nadpisaniami przeglądarki, nie fizyczną siecią. Surowy agresywny stres zachowuje 1 diagnostykę WebKit podczas opuszczania dokumentu. Niezależny kontrolowany test odtworzył jej promocję z konsoli do Playwright pageerror także przy obsłużonym fetch; nie wyciszano żadnej kontroli pełnej macierzy. [Dowody QA i ograniczenia](../audit/2026-10-08/RAPORT.md).

const router = useRouter();
const prefetchInvoice = () => {
  const connection = (navigator as Navigator & {
    connection?: { saveData?: boolean; effectiveType?: string };
  }).connection;
  if (connection?.saveData || /^(slow-)?2g$/.test(connection?.effectiveType || "")) return;
  router.prefetch("/invoices/new");
};
<Link href="/invoices/new" prefetch={false}
